Buscamos un perfil junior para desarrollo y mantenimiento de aplicaciones para nuestros clientes, con conocimientos en las siguientes tecnologías:

- HTML5
- CSS3
- Bootstrap
- Responsive Web Design
- PHP, con experiencia con frameworks como Codeigniter, Laravel o Symfony
- Javascript (JQuery)
- MySQL
- Valorable conocimientos con Angular o Vue
- Habituado a trabajar con control de versiones: GIT + Bitbucket


Requisitos:

- Disponibilidad a jornada completa
- Proactividad, autogestión de proyectos y organización son claves para el puesto
- Persona dinámica, resolutiva y polivalente
- Flexibilidad y capacidad de trabajar en múltiples proyectos simultáneamente
- Atención y cuidado por el detalle
- Riguroso con los plazos de entrega
- ¡Ganas! (actitud)
